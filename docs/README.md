# Productivity App: Documentation

> Working name. A lightweight, always-running desktop app that plans your day with you,
> tells you what to do *now*, adapts when life happens, and shows you how you're doing.

**Status:** Planning · **Current target:** v0.1 (personal MVP) · **Last updated:** 2026-11-10

## How to use these docs

- **Planning a feature?** Check it exists in the [Feature Catalog](02-feature-catalog.md) and which version it belongs to in the [Roadmap](03-roadmap.md).
- **Building v0.1?** The [v0.1 Spec](04-v0.1-spec.md) is the source of truth. If behavior isn't specified there, decide and record it in [Decisions](06-decisions.md).
- **Found a new need while using the app?** Add it to the Feature Catalog under "Ideas inbox" first, then decide which version it belongs to.
